# Henrique do Vale

Engenheiro de Software Sênior e Tech Lead. Fundador da [Opsyn](https://opsyn.com.br).

Construo ecossistemas escaláveis, automatizo processos complexos e desenvolvo sistemas autônomos de IA para resolver problemas reais de negócio.

### Trabalho e Foco
* **Engenharia de Software & Arquitetura:** Liderança técnica no ecossistema GestorDiniz, centralizando operações em larga escala para o varejo ótico.
* **IA Aplicada & Agentes:** Arquitetura de soluções inteligentes utilizando RAG avançado, Model Context Protocol (MCP), LangChain e bancos de dados vetoriais (Vector DBs).
* **Automação de Processos:** Soluções sob medida, indo desde pipelines de extração de dados em PDFs até integrações de alta disponibilidade com a WhatsApp Cloud API.

### Stack Principal
**Core:** TypeScript · Node.js · NestJS · React  
**IA & Dados:** MCP · RAG · LangChain · Vector DBs  
**Infra:** Docker · CI/CD · Linux
